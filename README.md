# Stellar Academy

Responsive educational website UI built with HTML5, CSS3, and vanilla JavaScript.

## Scope

- Responsive landing page
- Program and admissions sections
- Scroll-based interactions
- Animated statistics and navigation
- Mobile-friendly layout

This is a **frontend design/implementation project**, not a complete school management or learning platform.

## Stack

HTML5 · CSS3 · JavaScript · Flexbox · CSS Grid · Intersection Observer

## Engineering focus

Semantic markup, reusable styling patterns, responsive layout behavior, and lightweight client-side interactions.
